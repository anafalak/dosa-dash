Put your artwork in this folder:

    dosa.png      the player (the dosa)
    chutney.png   the collectible (the chutney)

- PNG with a transparent background works best.
- Any size is fine: the game crops empty padding and scales the image for you
  (dosa -> 112 px tall, chutney -> 58 px tall).
- Face the dosa to the RIGHT (it runs left-to-right).
- File names must match exactly (lower-case).
- If a file is missing, the game draws a simple placeholder instead.
